40 Linux Commands You Actually Need

Nov 3, 2026

These are the commands I use almost every day when working on Linux servers. If you're getting into sysadmin, DevOps or security work, start here.

If you only learn ten, learn these first: ls, cd, pwd, mkdir, cp, mv, grep, find, chmod and sudo.

Commands by Task

Don't try to remember the list. Remember the job. When something happens, these are the commands I run, in this order.

"The site is down"

systemctl status nginx → journalctl -u nginx → ss -tulpn → curl -I localhost

"The server is slow"

top → free -h → df -h → du -sh /var/*

"The disk is full"

df -h → du -sh /var/* | sort -h → find / -size +500M → rm

"Port is already in use"

ss -tulpn | grep :3000 → ps aux | grep node → kill PID

"Permission denied"

ls -l → chmod → chown → sudo

"Can't reach the server or domain"

ping → dig +short → ip addr → ip route

"Find an error in the logs"

tail -f → grep -i "error" → less → journalctl -u

"Deploy something"

ssh → rsync -avz → tar -xzf → systemctl restart

"Set up a new server"

apt update → useradd -m → usermod -aG sudo → ssh-copy-id → systemctl enable

"Back up files every night"

tar -czf → rsync -avz → crontab -e

Files and Folders

1. pwd

Shows the folder you're in right now. Useful when you get lost.

Example:

pwd
/home/rezwan

2. ls

Lists files and folders. Add -l for details, -a to show hidden files and -h for readable sizes.

Example:

ls
ls -lah

3. cd

Changes the folder you're in.

Example:

cd /var/log     # go to a folder
cd ..           # go up one folder
cd ~            # go to your home folder
cd -            # go back to the last folder

4. mkdir

Creates a new folder. Use -p to create folders inside folders in one go.

Example:

mkdir test
mkdir -p projects/app/logs

5. touch

Creates an empty file. If the file already exists, it just updates its time.

Example:

touch file.txt

6. cp

Copies files. Use -r to copy a whole folder.

Example:

cp file.txt backup.txt
cp -r website website-backup

7. mv

Moves a file to another place. It's also how you rename a file in Linux.

Example:

mv backup.txt newfile.txt        # rename
mv newfile.txt /tmp/             # move

8. rm

Deletes files. Use -r to delete a folder. Be careful: there's no recycle bin, so deleted files are gone for good.

Example:

rm newfile.txt
rm -r old-folder

Reading and Editing Files

9. cat

Prints the whole file in the terminal. Best for short files.

Example:

cat file.txt

10. less

Opens big files one page at a time. Use the arrow keys to scroll, /word to search and q to quit.

Example:

less /var/log/syslog

11. nano

A simple text editor, good for beginners. Press Ctrl+O to save and Ctrl+X to exit.

Example:

nano /etc/hosts

12. vim

A powerful editor that's on almost every server. Press i to start typing, then Esc and :wq to save and quit. :q! quits without saving.

Example:

vim config.yml

Searching

13. grep

Searches for text inside files. -i ignores upper and lower case, -r searches inside folders and -n shows line numbers.

Example:

grep "error" /var/log/syslog
grep -rin "password" /etc/

14. find

Finds files and folders by name, type, size or date.

Example:

find /home -name "*.txt"
find /var/log -size +100M
find . -type d -name "node_modules"

Permissions and Packages

15. chmod

Changes who can read, write or run a file. 755 means the owner can do everything, and others can only read and run it.

Example:

chmod 755 script.sh
chmod +x script.sh      # make it runnable

16. chown

Changes the owner of a file. Use -R to change a whole folder.

Example:

sudo chown rezwan:rezwan file.txt
sudo chown -R www-data:www-data /var/www

17. sudo

Runs a command as the admin (root) user. You need it for anything that changes the system, like installing software or editing system files.

Example:

sudo apt update

18. apt

Installs, updates and removes software on Ubuntu and Debian. On RHEL, Rocky or Fedora, use dnf instead.

Example:

sudo apt update            # refresh the package list
sudo apt install nginx     # install
sudo apt upgrade           # update everything
sudo apt remove nginx      # uninstall

Processes

19. ps

Shows running processes. Pair it with grep to find a specific one.

Example:

ps aux
ps aux | grep nginx

20. top

Shows live CPU and memory usage, and which processes use the most. Press q to quit. htop is a nicer version if it's installed.

Example:

top

21. kill

Stops a process using its PID (the number from ps or top). Use -9 only if it won't stop normally.

Example:

kill 1234
kill -9 1234

Disk and Network

22. df

Shows how much space is free on each disk. The first thing to check when a server acts weird.

Example:

df -h

23. du

Shows how much space a folder uses. Great for finding what filled up the disk.

Example:

du -sh /home
du -sh /var/* | sort -h

24. ip

Shows network info like IP addresses and routes. It replaces the older ifconfig.

Example:

ip addr      # your IP addresses
ip route     # your gateway and routes

Services

25. systemctl

Starts, stops and checks services like nginx or ssh. Use enable to make a service start on boot.

Example:

systemctl status nginx
sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl restart nginx
sudo systemctl enable nginx

DevOps Essentials

These are the commands you need once you start working on remote servers: connecting, moving files, reading logs and checking the network.

One thing to learn first is the pipe |. It sends the output of one command into the next one, so you can combine small commands into useful ones.

Example:

grep "error" app.log | wc -l        # count error lines
ps aux | grep nginx                 # find a process
ls -lt | head -5                    # 5 newest files

26. ssh

Connects you to a remote server's terminal. Most people use SSH keys instead of passwords because they're safer.

Example:

ssh user@192.0.2.10
ssh -i key.pem ubuntu@192.0.2.10     # log in with a key file
ssh-keygen -t ed25519                # create your own key
ssh-copy-id user@192.0.2.10          # copy your key to the server

27. scp

Copies files between your computer and a server over SSH. Use -r for folders.

Example:

scp app.zip user@192.0.2.10:/home/user/     # upload
scp user@192.0.2.10:/var/log/app.log .       # download
scp -r dist user@192.0.2.10:/var/www/        # upload a folder

28. rsync

Like scp, but smarter. It only copies files that changed, so it's great for deployments and backups.

Example:

rsync -avz dist/ user@192.0.2.10:/var/www/site/
rsync -avz --delete dist/ user@192.0.2.10:/var/www/site/   # also remove deleted files

29. curl

Sends requests to URLs from the terminal. Use it to test APIs, check if a site is up or download files.

Example:

curl https://example.com
curl -I https://example.com                  # headers only (status code)
curl -O https://example.com/file.zip         # download a file
curl -X POST -H "Content-Type: application/json" \
     -d '{"name":"test"}' https://api.example.com/users

30. tar

Packs many files into one archive, or unpacks it. c = create, x = extract, z = gzip, f = file name.

Example:

tar -czf backup.tar.gz /var/www       # create
tar -xzf backup.tar.gz                # extract
tar -tzf backup.tar.gz                # list what's inside

31. tail

Shows the last lines of a file. With -f it keeps watching the file and shows new lines live. Press Ctrl+C to stop.

Example:

tail -n 50 app.log
tail -f /var/log/nginx/access.log

32. journalctl

Shows logs for systemd services. When a service won't start, this is where you find out why.

Example:

journalctl -u nginx                   # logs for nginx
journalctl -u nginx -f                # watch live
journalctl -u nginx --since "1 hour ago"

33. ss

Shows which ports are open and which program is using them. Useful when an app says "port already in use".

Example:

sudo ss -tulpn
sudo ss -tulpn | grep :80

34. ping

Checks if a server is reachable and how fast it answers. Use -c to stop after a few tries.

Example:

ping -c 4 google.com

35. dig

Checks DNS records for a domain. Handy after you point a domain to a new server. I wrote more about DNS in this post.

Example:

dig +short example.com
dig example.com MX

36. crontab

Runs commands on a schedule, like a daily backup. The five fields are minute, hour, day, month and weekday.

Example:

crontab -e        # edit your scheduled jobs
crontab -l        # list them

# run backup.sh every day at 2:00 AM
0 2 * * * /home/user/backup.sh

37. useradd

Creates a new user. Use usermod to add a user to a group, and don't forget the -a, or the user gets removed from their other groups.

Example:

sudo useradd -m -s /bin/bash deploy   # create user with home folder
sudo passwd deploy                    # set password
sudo usermod -aG sudo deploy          # give admin rights
sudo usermod -aG docker deploy        # allow using docker

38. free

Shows how much memory (RAM) is used and free. uptime is a good partner: it shows how long the server has been running and how busy it is.

Example:

free -h
uptime

39. export

Sets an environment variable. Apps read these for settings like passwords or API keys. It only lasts until you close the terminal, unless you add it to ~/.bashrc.

Example:

export NODE_ENV=production
echo $NODE_ENV           # show one variable
env                      # show all variables

40. ln

Creates a link to another file or folder. With -s it makes a symlink, which works like a shortcut. Nginx uses this to turn sites on.

Example:

sudo ln -s /etc/nginx/sites-available/mysite /etc/nginx/sites-enabled/
